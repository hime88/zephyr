AUTOMATION · AUTOLISP REFERENCE

Your .lsp files run here.

Zephyr ships a native AutoLISP engine with the full inventoried builtin set — verified against every documented example. Routines you wrote for full AutoCAD run unmodified: entity creation and editing, selection sets, system variables, file I/O, dictionaries, layer states, and scripted (command …) calls — identically on macOS, Windows, and Linux.

COMMANDALIASDESCRIPTION
LOAD—Load and evaluate a .lsp file
EVAL—Evaluate a single Lisp expression string
SCRIPTSCRRun a .scr command script

Scripted (command …) calls include "INSERT" / "-INSERT" and, for images and PDFs, "-ATTACH" with AutoCAD's operand order: (command "-ATTACH" path [page] point [scale [rotation]]). Drawing attaches stay interactive (XATTACH). The xref system variables REFPATHTYPE, VISRETAIN, BINDTYPE, XDWGFADECTL, XREFNOTIFY, and XLOADCTL are readable and settable through getvar/setvar, and (tblsearch "BLOCK" name) returns an xref's saved path (group 1) and flags (group 70).

;; Color all circles red
(setq ss (ssget "_X" '((0 . "CIRCLE"))))
(setq i 0)
(repeat (sslength ss)
  (setq e (entget (ssname ss i)))
  (entmod (if (assoc 62 e)
            (subst '(62 . 1) (assoc 62 e) e)
            (append e (list '(62 . 1)))))
  (setq i (1+ i)))
